# sevinchim.uz

Радио бошловчининг расмий шахсий сайти: жонли FM радио, архив дастурлар ва эфир жадвали. Сайт PWA форматида, телефонда илова каби ишлайди.

**Стек:** Next.js 16 (App Router), React 19, Tailwind CSS 4, hls.js, Media Session API, Service Worker.

## Бошқарув панели (`/admin`)

Телефон ёки компьютердан кириб, қуйидагиларни қилиш мумкин:

- **Telegram бот** («Telegram» бўлими): BotFather берган калитни киритиб «Улаш» босилади, кейин «код олиш» тугмаси орқали Telegram аккаунт уланади. Ботда учта тугма: «● Ёзишни бошлаш», «■ Тўхтатиш», «ℹ️ Ҳолат» (ёки `/yoz [рукн]`, `/toxta`, `/holat`). Ёзув тугагач бот хабар юборади ва «📢 Чоп этиш» тугмасини беради. Бот сайт ичида ишлайди (webhook `/api/telegram`), қўшимча хотира олмайди; созламалар `DATA_DIR/telegram.json` да.
- **Эфирни ёзиб олиш:** «● Ёзишни бошлаш» тугмаси радионинг расмий оқимини серверда ёза бошлайди, «■ Тўхтатиш» билан тугайди (ёки 3 соат 30 дақиқадан кейин ўзи тўхтайди). Ёзув архивга **қоралама** бўлиб тушади — сайтда кўринмайди, текшириб «Чоп этиш» босилганда чиқади. Оқим узилса қайта уланади ва қисмларни бирлаштиради; сервер қайта ишга тушса ёзилгани сақланади. Серверда `ffmpeg` керак (`deploy/setup.sh` ўрнатади). Созламалар: `RECORD_MAX_SECONDS` (стандарт 12600), `RECORD_BITRATE` (стандарт `128k`).
- **Архив:** янги эшиттириш аудиосини юклаш (1 ГБ гача, 50 МБ лик бўлакларда — Cloudflare лимитига мос; юклаш жараёни кўрсатилади, узилса давом этади). Мавжуд эшиттиришларни таҳрирлаш ва ўчириш.
- **Эфир жадвали:** кун, вақт, дастур номи ва «муаллифлик дастури» белгиси.
- **FM оқим:** радио оқими ҳаволаларини ва сифат вариантларини янгилаш.
- **Анонслар:** «Медиа» саҳифасидаги дастурлар анонси.

Сақлаганда ўзгаришлар сайтда дарҳол кўринади (ISR қайта генерацияси).

## Ишга тушириш

```bash
npm ci
```

```bash
cp .env.example .env    # ADMIN_PASSWORD ва SESSION_SECRET ни тўлдиринг
```

```bash
npm run build
```

```bash
npm start               # http://localhost:3000
```

Ишлаб чиқиш режими: `npm run dev`.

### Муҳит ўзгарувчилари

| Ўзгарувчи | Тавсиф |
|---|---|
| `ADMIN_PASSWORD` | Админ-панель пароли (камида 8 белги, 12+ тавсия этилади) |
| `SESSION_SECRET` | Сессия калити: `openssl rand -hex 32` |
| `DATA_DIR` | Маълумотлар ва юкланган аудиолар папкаси (бўлмаса `./data`). Серверда лойиҳадан ташқарида сақланг, масалан `/var/lib/sevinchim` |
| `NEXT_PUBLIC_SITE_URL` | `https://sevinchim.uz` |

## Серверга жойлаштириш

Тўлиқ йўриқнома: **[docs/DEPLOY.md](docs/DEPLOY.md)** (Oracle Cloud ёки ҳар қандай Ubuntu VPS ва Cloudflare).

Қисқача: Ubuntu 22.04 ёки 24.04 серверда шу битта буйруқни ишга туширинг. Буйруқ Node.js, nginx, HTTPS, systemd ва файрволни ўзи созлайди:

```bash
curl -fsSL https://raw.githubusercontent.com/minimalluz/sevinchim.uz/main/deploy/setup.sh | bash
```

Шу буйруқни қайта ишга туширсангиз, сайт янгиланади. `.env` ва юкланган аудиолар сақланиб қолади.

**Захира нусха:** фақат `DATA_DIR` папкасини (`content.json` ва `audio/`) сақлаш кифоя.

## Ишга туширишдан олдин алмаштириш керак

Ҳозирги маълумотлар намуна учун берилган, ҳаммаси `data/content.json` да:

- **Бошловчи:** `profile` — исм (ҳозир «Севинч»), радиостанция номи ва частотаси (ҳозир «Эхо долины», 102.7 FM), таржимаи ҳол, фаолият тарихи, ижтимоий тармоқлар.
- **Суратлар:** бошловчининг ҳақиқий суратлари `public/media/sevinch-*.jpg` да (метамаълумотлари ўчирилган). Бош саҳифа — `profile.photo`, «Мен ҳақимда» — `profile.aboutPhoto` (`aboutPhotoFocus` — юз турган нуқта). Янги суратни шу папкага қўйиб, `data/content.json` да номини ёзинг: Next.js уни AVIF/WebP га ўзи ўгиради.
- **Радио оқими:** `streams` — ҳозир бўш, шунинг учун «Жонли эфир» тугмалари `liveFallback` саҳифасини (Mediabay) янги ойнада очади. Радиостанциядан расмий оқим манзили (Icecast/HLS, `https://`) олингач, уни админ-панелдаги «FM оқим» бўлимига киритинг: сайт ўз плеерига ўзи ўтади.
- **Архив:** 9 та демо эшиттириш ва `data/audio/demo-*.mp3` (90 сониялик тест оҳанглари). Админ-панел орқали ўчириб, ҳақиқийларини юкланг.
- **Галерея:** `gallery` — 5 та ҳақиқий сурат. Видео учун `"type": "video"` ва `"video": "<YouTube ID ёки mp4 манзили>"` ёзинг. Охирги сурат жадвал тўлиши учун кенг кўрсатилиши мумкин — у ерга кенг (горизонтал) сурат қўйган маъқул.
- **Иконкалар:** `public/icons/` — `node scripts/icons.mjs` билан қайта яратилади.

## Тезлик (Lighthouse, production)

| | Performance | Accessibility | Best Practices | SEO |
|---|---|---|---|---|
| Мобил (барча 5 саҳифа) | 91–93 | 100 | 100 | 100 |
| Десктоп | 100 | — | — | — |

Десктопда LCP 0,7 с, FCP барча саҳифаларда 0,8 с. Мобилда Lighthouse атайлаб секин 4G тармоғини симуляция қилади ва LCP 3,2–3,5 с чиқади.

ТЗ даги «LCP ≤ 1,2 с» мақсадига ҳақиқий тармоқда (4G/Wi-Fi, TAS-IX сервер) эришиш кутилади. Бунинг учун:
- серверни Ўзбекистонда (TAS-IX) ёки CDN орқасида жойлаштиринг;
- ҳақиқий суратни сиқиб қўйинг (ўзи AVIF га ўгирилади).
